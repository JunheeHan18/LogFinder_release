# LogFinder Release

This repository is used to distribute LogFinder release packages.

## Latest Release

- Version: `2.7.0.0`
- Download: https://github.com/JunheeHan18/LogFinder_release/releases/latest
- Notes: `RELEASE_NOTES_2.7.0.0.md`

## Install

1. Download `LogFinder_v2.7.0.0.zip` from the Releases page.
2. Unpack it and run `LogFinder.exe`.

Requires the .NET 8 Desktop Runtime (x64). Keep the `docs` folder next to `LogFinder.exe` so Help can show the user manual.
